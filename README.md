# Catálogo y lista de precios — Placares Schinner

Página del catálogo de placares de Schinner, con los precios del día.

Los precios salen de la planilla «Schinner - lista de precios». Cuando ahí se sube o se baja un porcentaje, la página muestra los precios nuevos al abrirla, y el botón «Descargar PDF» guarda el catálogo completo con esos precios.

Si la página no puede leer la planilla, avisa en rojo y no deja descargar el PDF, para que nunca salga un catálogo con precios viejos.
